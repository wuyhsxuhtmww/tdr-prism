## Overview

TDR Prism is a high-resolution multiband dynamic equalizer designed for mastering, combining precise static EQ with transparent dynamic gain riding for natural results.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **TDR Prism** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Dynamic EQ** | Up to 5 dynamic bands with per-band threshold and ratio control |
| **Linear Phase** | Switchable linear phase mode for mastering without pre-ringing artifacts |
| **Spectrum Analyzer** | High-resolution real-time spectrum display with peak hold |
| **Mid/Side** | Full mid/side processing mode for stereo field correction |
